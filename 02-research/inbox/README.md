# Research Inbox

Drop new raw material here between synthesis runs — an exported support-ticket CSV, a batch of new NPS comments, a pasted chat log of user feedback, anything not yet synthesized. Any format is fine; the `research-synthesis` skill (`skills/research-synthesis.md`) reads whatever's here, synthesizes it, and archives it once processed.

If this folder is empty, that's the honest signal that there's nothing new to synthesize yet — not a reason to invent findings.
